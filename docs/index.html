Capabilities

Built to demonstrate real AI engineering

Every feature maps directly to what enterprise AI Engineer roles require.

Persistent Memory
Every conversation stored in PostgreSQL via Neon. Start a new session days later — the agent remembers exactly where you left off.
Real-Time Web Search
Tavily integration gives the agent reliable access to current events, news, and anything outside its training data — works on cloud deployments.
Document Q&A (RAG)
Upload PDF, TXT, or Markdown files. ChromaDB + sentence-transformers retrieves the most relevant chunks and injects them as context before every response.
Custom LangGraph Agent
Built with StateGraph and ToolNode from scratch — not create_react_agent — for direct control over tool binding, parallel_tool_calls, and message flow.
LangSmith Observability
Every agent invocation traced: tool calls, token usage, latency, full message trees. Production-grade MLOps observability out of the box.
Zero Cost Stack
Groq, Neon, ChromaDB, Streamlit Cloud, Tavily — all free tier. Demonstrates cost-consciousness and deployment know-how at $0/month to run.
Architecture

How it works

Each message triggers a full agentic loop: RAG retrieval, LLM reasoning, optional tool call, and PostgreSQL persistence.

agent.py — request flow
User Input │ ├── RAG: retrieve_context(query) │ ├── ChromaDB similarity search │ └── all-MiniLM-L6-v2 embeddings │ (always runs — injected into system prompt) │ ▼ LangGraph StateGraph │ ├── agent_node │ └── ChatGroq · llama-3.1-8b-instant · streaming=False │ │ │ tool_calls? ──► ToolNode │ │ └── search_web() · Tavily API │ │ │ final response │ ▼ PostgreSQL (Neon) ──► persist human + assistant messages │ ▼ LangSmith ──► trace every invocation (tool calls · latency · tokens)
