Persistent Long-Term Memory

Every conversation stored in PostgreSQL with JSONB message format, triggers for session tracking, and composite indexes. Survives restarts, deployments, and device changes.

SQLChatMessageHistory · Supabase
📚

RAG — Knowledge Base Search

Upload PDF, TXT, or Markdown files. Documents are chunked, embedded with all-MiniLM-L6-v2, and stored in ChromaDB. The agent retrieves top-k chunks before answering.

ChromaDB · sentence-transformers · LangChain
🤖

LangGraph ReAct Agent

A stateful graph-based agent that reasons step-by-step and decides which tool to use. Built with LangGraph's create_react_agent and a MemorySaver checkpointer.

LangGraph · ReAct · Tool Calling
🌐

Real-Time Web Search

DuckDuckGo search tool requires no API key. The agent automatically searches the web when it needs current information not in its training data or knowledge base.

duckduckgo-search · Function Calling
⚡

Streaming Responses

Tokens stream progressively to the UI using Groq's streaming API and Streamlit's st.write_stream(). No waiting for the full response — instant feedback.

Groq Streaming · st.write_stream
🔬

LangSmith Observability

Every agent invocation auto-traced in LangSmith. Full trace trees showing tool calls, token counts, latency, and LLM inputs/outputs. Production MLOps in 5 lines of code.

LangSmith · MLOps · Tracing

What is RAG and how does it work?
🧠
📚 retrieve_from_documents("RAG")

RAG (Retrieval Augmented Generation) grounds LLM responses in external knowledge. The pipeline has 5 steps: Ingest → Embed → Store → Retrieve → Generate. Your documents are split into 500-token chunks, embedded using all-MiniLM-L6-v2, stored in ChromaDB, and retrieved via similarity search at query time...
